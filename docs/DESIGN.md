# VEX训练数据管理 · Design System

## Direction

参考图的核心不是营销页结构，而是精密黑白秩序：中性浅灰背景、白色工作表面、黑色高权重操作、细腻分隔、克制阴影和紧凑排版。产品界面减少装饰，把视觉层级用于训练任务、同步状态和成绩数据。

## Color

- Canvas: `oklch(0.965 0 0)`
- Surface: `oklch(0.995 0 0)`
- Surface muted: `oklch(0.94 0 0)`
- Ink: `oklch(0.16 0 0)`
- Muted ink: `oklch(0.46 0 0)`
- Hairline: `oklch(0.88 0 0)`
- Primary: `oklch(0.16 0 0)`
- Success: `oklch(0.66 0.17 145)`
- Warning: `oklch(0.72 0.16 70)`
- Danger: `oklch(0.60 0.22 25)`
- Info: `oklch(0.60 0.16 250)`

强调色只用于状态和选择，不作为大面积装饰。

## Typography

使用系统无衬线字体栈：`Inter, SF Pro Text, PingFang SC, system-ui, sans-serif`。产品界面采用固定字号层级：12、14、16、18、22、28px。数字使用等宽数字特性。标题字距不小于 `-0.03em`。

## Layout

- 手机为默认布局，主要内容宽度占满可用区域。
- 页面水平安全间距 16px；密集录入区域可使用 12px。
- 底部导航保留，但核心“开始记录”操作必须在单手拇指范围内。
- 桌面端最大内容宽度 1120px，增加侧栏或双栏，不简单拉伸手机界面。
- 数据列表优先使用行、分组和分隔线，卡片仅用于真正独立的任务单元。

## Components

- 按钮：主按钮黑底白字；次按钮浅灰；危险操作红色文字或红底确认。按钮高度至少 44px。
- 输入框：白色或浅灰表面，清晰焦点环，错误状态包含文字说明。
- 训练记录行：队员、轮次、成绩、保存状态在一行内形成明确层级。
- 同步状态：已同步、同步中、离线待同步、失败四种状态使用图标、文字和颜色共同表达。
- 底部操作条：用于快速计时、保存下一位和批量保存，避免频繁打开弹窗。
- 弹层：只用于确认或短任务；队员管理、模板配置优先使用独立页面或内联展开。

## Motion

交互反馈控制在 150–220ms。动画只表达状态变化。支持 `prefers-reduced-motion: reduce`，不使用页面入场编排或弹性动画。

## Reference Translation

保留参考图中的高留白、精确对齐、克制黑白、轻微悬浮和少量状态色；放弃营销页的大标题、巨幅空白、强烈按钮阴影及展示性设备模型。训练界面以可扫读性和单手效率为第一标准。
